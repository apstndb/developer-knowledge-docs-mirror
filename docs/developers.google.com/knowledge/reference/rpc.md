The Developer Knowledge API provides access to Google's developer knowledge.

## Service: developerknowledge.googleapis.com

The Service name `developerknowledge.googleapis.com` is needed to create RPC client stubs.

## [`google.developers.knowledge.v1.DeveloperKnowledge`](https://developers.google.com/knowledge/reference/rpc/google.developers.knowledge.v1#google.developers.knowledge.v1.DeveloperKnowledge)

| Methods                                                                                                                                                                               |                                                                           |
|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------|
| [`AnswerQuery`](https://developers.google.com/knowledge/reference/rpc/google.developers.knowledge.v1#google.developers.knowledge.v1.DeveloperKnowledge.AnswerQuery)                   | Answers a query using grounded generation.                                |
| [`BatchGetDocuments`](https://developers.google.com/knowledge/reference/rpc/google.developers.knowledge.v1#google.developers.knowledge.v1.DeveloperKnowledge.BatchGetDocuments)       | Retrieves multiple documents, each with its full Markdown content.        |
| [`GetDocument`](https://developers.google.com/knowledge/reference/rpc/google.developers.knowledge.v1#google.developers.knowledge.v1.DeveloperKnowledge.GetDocument)                   | Retrieves a single document with its full Markdown content.               |
| [`SearchDocumentChunks`](https://developers.google.com/knowledge/reference/rpc/google.developers.knowledge.v1#google.developers.knowledge.v1.DeveloperKnowledge.SearchDocumentChunks) | Searches for developer knowledge across Google's developer documentation. |
