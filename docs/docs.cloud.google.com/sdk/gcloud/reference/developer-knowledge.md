NAME

gcloud developer-knowledge - manage Developer Knowledge resources and query knowledge base

SYNOPSIS

`gcloud developer-knowledge` [`GROUP`](https://docs.cloud.google.com/sdk/gcloud/reference/developer-knowledge#GROUP) \| [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/developer-knowledge#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/developer-knowledge#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

Manage Developer Knowledge resources and query knowledge base.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

GROUPS

`GROUP` is one of the following:

[`documents`](https://docs.cloud.google.com/sdk/gcloud/reference/developer-knowledge/documents)  
Explore and search Developer Knowledge documents.

COMMANDS

`COMMAND` is one of the following:

[`answer-query`](https://docs.cloud.google.com/sdk/gcloud/reference/developer-knowledge/answer-query)  
Answer a natural language query using grounded generation.

NOTES

These variants are also available:

```
gcloud alpha developer-knowledge
```

```
gcloud beta developer-knowledge
```
