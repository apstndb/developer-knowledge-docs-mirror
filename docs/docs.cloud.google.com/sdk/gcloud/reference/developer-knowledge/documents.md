NAME

gcloud developer-knowledge documents - explore and search Developer Knowledge documents

SYNOPSIS

`gcloud developer-knowledge documents` [`COMMAND`](https://docs.cloud.google.com/sdk/gcloud/reference/developer-knowledge/documents#COMMAND) \[ [`GCLOUD_WIDE_FLAG`](https://docs.cloud.google.com/sdk/gcloud/reference/developer-knowledge/documents#GCLOUD-WIDE-FLAGS)` …` \]

DESCRIPTION

Explore and search Developer Knowledge documents.

GCLOUD WIDE FLAGS

These flags are available to all commands: [`--help`](https://docs.cloud.google.com/sdk/gcloud/reference#--help) .

Run `$ `[`gcloud help`](https://docs.cloud.google.com/sdk/gcloud/reference) for details.

COMMANDS

`COMMAND` is one of the following:

[`describe`](https://docs.cloud.google.com/sdk/gcloud/reference/developer-knowledge/documents/describe)  
Retrieve a single document with its full Markdown content.

[`search-chunks`](https://docs.cloud.google.com/sdk/gcloud/reference/developer-knowledge/documents/search-chunks)  
Search for developer knowledge across Google's developer documentation.

NOTES

These variants are also available:

```
gcloud alpha developer-knowledge documents
```

```
gcloud beta developer-knowledge documents
```
