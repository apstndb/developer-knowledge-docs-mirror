NAME

gcloud alpha developer-knowledge - manage Developer Knowledge resources and query knowledge base

SYNOPSIS

`gcloud alpha developer-knowledge` `  GROUP  ` | `  COMMAND  ` \[ `  GCLOUD_WIDE_FLAG …  ` \]

DESCRIPTION

`(ALPHA)` Manage Developer Knowledge resources and query knowledge base.

GCLOUD WIDE FLAGS

These flags are available to all commands: `  --help  ` .

Run ` $ gcloud help  ` for details.

GROUPS

`  GROUP  ` is one of the following:

  - `  documents  `  
    `(ALPHA)` Explore and search Developer Knowledge documents.

COMMANDS

`  COMMAND  ` is one of the following:

  - `  answer-query  `  
    `(ALPHA)` Answer a natural language query using grounded generation.

NOTES

This command is currently in alpha and might change without notice. If this command fails with API permission errors despite specifying the correct project, you might be trying to access an API with an invitation-only early access allowlist. This variant is also available:

    gcloud beta developer-knowledge
